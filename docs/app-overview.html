Call Center Voice Agent Accelerator

Azure Voice Live API ile çalışan, gerçek zamanlı konuşmadan-konuşmaya (speech-to-speech) yapay zekâ ses ajanı. Tarayıcıdan veya gerçek telefon hattından arayan müşteriyi anında dinler, anlar ve sesli yanıtlar.

Ne yapar?

🎙️

Gerçek zamanlı ses sohbeti

Düşük gecikmeli ASR (konuşma tanıma) + LLM + TTS tek bir API üzerinden; ayrı servisleri birbirine bağlamaya gerek yok.

📞

Gelen çağrıları karşılar

PSTN telefon numarasına gelen aramaları otomatik cevaplar; müşteri temsilcisi gibi konuşur.

🌐

Tarayıcıdan test

Web istemcisi ile mikrofon/hoparlör üzerinden telefon olmadan hızlıca denenir.

🧠

Foundry Agent desteği

Mevcut bir Azure AI Foundry Agent'a bağlanıp bilgi tabanı ve orkestrasyon yeteneklerini kullanır.

🏢

Ortam sesi (Ambient)

Ofis veya çağrı merkezi arka plan sesi ekler; kendi ses dosyalarınızı da tanımlayabilirsiniz.

⚙️

Özelleştirilebilir

Prompt, ASR, TTS sesi ve model (gpt-4o-mini, gpt-4.1, gpt-5 vb.) yeniden dağıtım yapmadan değiştirilebilir.

Azure'a kurulum

azd up

Tek komutla kaynak grubu, Voice Live/AI Services, ACS, Container Apps, Container Registry, Key Vault ve izleme (App Insights) Bicep ile kurulur.

Model seçimi

12 yönetilen model (Pro/Basic/Lite). Sonradan AZURE_VOICE_LIVE_MODEL ile değiştirilir.

Post-deploy script

Webhook ve sağlayıcı ayarları (ör. Vonage uygulaması, numara bağlama) otomatik yapılır.

Dene

Web istemcisinde Start Talking to Agent ya da telefon numarasını arayın.

Kod yapısı

server/

Python backend: çağrı yönetimi, providers/ (sağlayıcı başına handler), ambient mixer, statik web istemci.

infra/

Bicep modülleri: aiservices, acs, containerapp, keyvault, identity, monitoring.

hooks/

azd kurulum ve post-deploy scriptleri.

docs/

Üretime hazırlık ve sorun giderme rehberleri.
